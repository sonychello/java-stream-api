# Java Stream API

A Java project demonstrating the use of the **Stream API** for processing collections and arrays.

All required operations are implemented using only the Stream API.

## Implemented Methods

The project contains methods for:

* calculating the average value of a list of integers;
* converting all strings to uppercase and adding the `_new_` prefix;
* finding the squares of elements that occur exactly once;
* finding and alphabetically sorting strings that start with a specified character;
* returning the last element of a collection or throwing an exception if it is empty;
* calculating the sum of even numbers in an integer array;
* converting a list of strings into a `Map`, where the first character is the key and the remaining characters form the value.

## Main Concepts

The project demonstrates:

* Java Stream API;
* `map`;
* `filter`;
* `sorted`;
* `distinct` and grouping operations;
* `reduce`;
* collectors;
* processing collections and arrays with streams.

## Technologies

* Java
* Stream API
* Collections Framework
* Lambda expressions

## Demonstration

The program demonstrates each implemented method using example collections and arrays.
